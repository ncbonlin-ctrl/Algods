# صندوق التكافل الاجتماعي - قبيلة الصيعان

منصة ويب تفاعلية مبنية بـ HTML و Tailwind CSS و JavaScript مع مزامنة فورية عبر Firebase Realtime Database ونسخ احتياطي تلقائي محلي.

## طريقة النشر على GitHub Pages

1. أنشئ مستودعاً جديداً (Repository) على **GitHub** (مثلاً `sayaan-takaful`).
2. ارفع ملف `index.html` إلى الفرع الرئيسي (`main`) في جذر المستودع.
3. من المستودع على GitHub، اذهب إلى **Settings** ← **Pages**.
4. تحت **Build and deployment** ← **Source**، اختر **Deploy from a branch**، ثم حدد الفرع `main` والمجلد `/ (root)` واضغط **Save**.
5. خلال دقائق ستصبح الصفحة متاحة على الرابط:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## ملاحظات تقنية

- تم تصحيح وسوم HTML وبنية JavaScript بالكامل ليعمل الملف كصفحة ويب مستقلة جاهزة للنشر المباشر.
- يُنصح بمراجعة قواعد الأمان في Firebase Realtime Database قبل الإطلاق الفعلي للجمهور.
